<product_requirements>
The application functions as a cross-platform (web-based) running coach, acting as an athlete's data vault to provide wise, practical guidance. It integrates with fitness trackers (Strava, Garmin, Oura, Coros) for a unified data timeline, nutrition logging, daily readiness scores, weekly training plans, and post-workout feedback. Core features include an AI coach for chat-based analysis, history browsing, custom insights, data export, and privacy management.

Implemented features include:
- An AI Coach powered by Claude and OpenAI, with conversation history and Markdown.
- User authentication (login, registration, logout), password reset, and multi-language support.
- User account management with configurable OpenAI API keys and user-input credentials for Strava, Oura, and Coros.
- Responsive UI with a mobile-friendly bottom navigation and a new slideout hamburger menu.
- A Schedules section for automated AI analysis prompts.
- Reports (formerly Recommendations) for AI insights and a Merits section for personal records.
- Comprehensive subscription system with pricing page, in-app plan management (upgrade, downgrade, cancel, resubscribe, billing cycle changes), invoice listing, and Stripe integration.
- New modules for Journaling (text/voice entry) and Nutrition logging (text/image entry), with a Training Calendar under development.
