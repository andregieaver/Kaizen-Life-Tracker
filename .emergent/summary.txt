<product_requirements>
The goal is to create a powerful, multi-modal **App Management Agent** exclusively for super admins, granting them full-system access to enhance app administration.

**Core Features Implemented:**
1.  **Full System Access:** The agent must be able to access and query all user data across the entire database and manage community content (posts, comments, etc.).
2.  **Multi-Modal Interface:** The agent must be accessible via both a text-based chat interface and a real-time advanced voice interface, using OpenAI models.
3.  **Dedicated UI:** A new Floating Action Button (FAB) was added to the dashboard, exclusively visible to the super admin (). This FAB replicates the app's existing glassmorphic style and fan-out animation, providing toggles for text and voice modes.
4.  **Agent-Led Navigation:** The agent can automatically redirect the admin to different pages within the application upon request (e.g., navigate to community).
5.  **Agent Management System:** A new Agents tab was added to the System Settings page. This allows the super admin to create, edit, and delete various AI agents, configuring their name, profile image, instructions, voice, and accessibility level (e.g., for logged-out users, logged-in members, or admins).
6.  **Public Chatbot Widget:** Agents designated with frontend accessibility appear in a chatbot widget on the public-facing landing page.
</product_requirements>
