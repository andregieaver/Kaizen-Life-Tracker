<product_requirements>
The application aims to be a cross-platform (initially web-based) running coach, acting as a data vault for athletes. It should provide wise, practical guidance by connecting fitness trackers (Strava, Garmin, Oura, Coros) to offer a unified data timeline, nutrition logging, daily readiness scores, weekly training plans, and post-workout feedback. Core features include an AI coach for chat-based analysis and planning, tools for history browsing, custom insights, data export, and privacy management.

So far, the product includes:
- An AI Coach powered by Claude (orchestrator) and OpenAI (text/voice), utilizing an Emergent LLM key or user's OpenAI key.
- A My Account page with personal info, OpenAI API key management, Strava, Oura, and Coros integrations.
- A responsive UI with a mobile-friendly bottom navigation bar.
- A Schedules section for defining and saving automated AI analysis prompts, with CRUD operations.
- A Reports page (formerly Recommendations) to display AI-generated insights, currently showing an empty state.
- Login, registration, and logout with password authentication.
- AI coach with chart generation, conversation history, and Markdown rendering.
- A Merits section for personal records.
- URL-based navigation for state persistence.
- Multi-language support initiated with a language selector.
</product_requirements>
