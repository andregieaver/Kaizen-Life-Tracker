<product_requirements>
The primary objective is to establish the TrainSmart application as a central hub for user health and fitness data by integrating with a comprehensive list of third-party wearable device and service providers.

**Core Requirements & Implementation:**
1.  **Multi-Provider Integration:** Implement end-to-end data integration for Strava, Oura, Polar, Fitbit, Garmin, COROS, WHOOP, and Suunto.
2.  **Robust Authentication:** Build secure connection flows for each provider using OAuth 2.0 (and OAuth 1.0a for Garmin), allowing users to connect their accounts.
3.  **Comprehensive Data Sync:** Enable both incremental (Sync Latest) and full historical (Sync All) data synchronization for activities, sleep, and key health vitals.
4.  **Feature Integration:** Surface the synchronized data within the application's core features:
    *   **Training Calendar:** Display completed activities from all connected providers.
    *   **AI Coach:** Feed activity, sleep, and readiness data into the coach's context for more personalized advice.
    *   **User Dashboards:** Show provider data on pages like Merits and Vitals cards.
5.  **Admin Configuration:** Provide a UI in the System Settings for administrators to manage API credentials (Client ID, Secret) for each integration.
</product_requirements>
