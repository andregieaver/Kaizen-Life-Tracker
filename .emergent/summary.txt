1.  **Enhanced Community Features**: Complete comment deletion (user's own comments on posts/events), improved user profiles with a personal wall for posts, and a Following feed displaying content from followed users and personal posts.
2.  **Post Management**: Ability to create posts with public or private visibility, edit posts (including visibility), and delete own posts.

4.  **Referral/Reward System**: Implement a system where existing users can invite new users with a unique link. This system requires a dedicated frontend page, backend API, referral code tracking, and seamless integration with the Stripe subscription checkout, including direct redirection to payment after signup.
