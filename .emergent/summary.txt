<product_requirements>
The application aims to be a cross-platform running coach (initially web-based) that acts as a vault for an athlete's body data, providing wise, practical guidance. Users should connect fitness trackers (Strava, Garmin, Oura, etc.) to see a unified data timeline, log nutrition, and receive daily Readiness scores, weekly training plans, and post-workout feedback. A core feature is an AI coach for chat-based analysis and planning, along with tools for browsing history and custom insights. The app must also support data export and privacy management.

So far, the product includes:
-   An AI Coach powered by Claude (orchestrator) and OpenAI (text/voice), initially using an Emergent LLM key, then user's own OpenAI key with fallback.
-   A My Account page with sections for personal information, OpenAI API key management, and placeholders for Strava and Oura integrations.
-   A responsive UI with a mobile-friendly bottom navigation bar.
-   A Schedules section for users to define and save automated AI analysis prompts.
-   A Recommendations page (replacing Log Data) to display AI-generated insights from these schedules, currently in an empty state.
</product_requirements>
